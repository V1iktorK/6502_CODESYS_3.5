## Что работает (проверено)
* Мини-ассемблер 6502 (`tools/asm6502.py`, двухпроходный) — собирает реальные
  программы: `A2 00 BD 0E 02 F0 06 8D 00 F0 E8 4C 02 02 02 43 50 2F 4D 20 4F 4B 00`.
* Консоль CP/M в окне: запись в `$F000` дописывает символ в `GVL_IO.Console`,
  чтение через `RD_ADR = $F100+i`. **В пошаговом режиме вывод реально идёт**
  (`CCPP//MM  OOKK` — с дублями из-за двойного такта).
* Диск: `GVL_DISK` 2048×128 = 256 КБ, регистры `$F010-$F013` (+`RdWr`),
  доступ через указатель на начало массива.

## Текущий эталон
`120/121` (коммит `b0d593b`), сборка 55/55 ПОУ, 0 ошибок. Не проходит только
`T091` (аппаратный баг страницы `JMP ($xxFF)`) + редкие флаки стенда.
