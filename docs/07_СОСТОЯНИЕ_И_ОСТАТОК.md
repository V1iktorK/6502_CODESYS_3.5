## 2. Найденные и устранённые корневые причины (важно для продолжения)

1. **Контактный выход ПОУ.** CODESYS не исполняет тело ПОУ, если его вызов
   ничего не читает (правило 3 конспекта). Поэтому у каждой ступени/слоя теперь
   есть `OUT : BOOL` и связка `TRUE -> OUT`, а композиция читает `inst.OUT`
   в `GVL_CPU.Chain1..8`. Без этого `ALU_R` был 0.
2. **Соглашение `SEL`.** В рантайме проверено: `G=TRUE -> IN1`, `G=FALSE -> IN0`.
   `SELb(s, g, a, b)` теперь означает «`g ? b : a`» и так и используется во всех
   местах вызова. Две перевёрнутые площадки в АЛУ исправлены.
3. **Чтение памяти по адресу, записанному в том же ПОУ** (правило 2.5) отдаёт
   старое значение. Поэтому `FB_Fetch` считает только `OP`, `PC1`, `PC2`, а байты
   операнда читает отдельный ПОУ `FB_FetchOp`.
4. **Регистр P.** Сборка через массивы битов (`F_UnpackByte`/`F_PackByte`) в
   рантайме не работала и вдобавок fan-out размножал цепочку до 2^7 копий.
   Теперь P собирается **конвейером коротких ступеней** `SL_FLG_N/Z/C/V/I/B` +
   `SL_FLG5` (по одному биту), состояние передаётся через `GVL_CPU.P_WORK`,
   каждая ступень работает только при `GVL_CPU.Enable`.
5. **Двойное чтение байта размножает схему.** Любая формула «изменить бит в
   байте» читает байт дважды; если читается *вычисленное* значение, fan-out
   клонирует всю входную цепочку. Правило: читать только входную переменную.
6. **Пульт.** `GVL_CPU.Run` по умолчанию `FALSE`: ядро стартует остановленным.
   Иначе до первого нажатия «Пуск» оно выполняло мусор по адресу сброса
   (в памяти нули -> `$00` = BRK), и BRK защёлкивал бит B в регистре P.

## 4. Остаток работ по ТЗ-1

1. Довести 121 кейс до 121/121. Текущие группы отказов:
   * `TAX/TAY/TXA/TYA` — флаги (`P` приходит $38 вместо $24): проверить, что
     `SL_FLG_*` получают именно свои сигналы (SEL/`Enable` в этих ступенях);
   * `LDX/LDY zeropage,Y` и `absolute,Y` — адресация с индексом Y;
   * `STX/STY zeropage,Y/X` — запись по адресу с индексом;
   * `ADC/SBC` — перенос/переполнение (`P` завышен);
   * два кейса падают на чтении несуществующего выражения
     («Значение выражения не может быть найдено») — адрес `post` вне `Mem`.
2. Пошаговые тесты `T-DEC/T-ALU/T-ADDR/T-PC`.
3. `T-BRK/T-RTI/T-SEI/T-CLI`.
4. `PRG_6502_CORE` с несколькими экземплярами ядра + `CTU` +
   `CPU_Insts_Per_Scan` (1…32) и `T-SYNC-1…4`.
5. Отчёт по ТЗ-1.

## 5. Остаток работ по ТЗ-2

1. Окно ввода-вывода `$F000–$F0FF`: подключить уже сгенерированные
   `FB_IOBridge`, `FB_IRQController`, `FB_AnalogBridge`, `FB_DiskImage`
   (`tools/gen_io.py`), объявить `GVL_IO`, `GVL_BUS`, `GVL_MAP`.

   `ARRAY[0..2047,0..127] OF BYTE`, загрузка `.COM` на `$0200`.
4. Тесты `T-MON-1…5`, `T-CPS-1/2`.
5. Панель HMI (пуск/останов/пошагово/память/экран), документация портфолио,
   итоговый отчёт.
